# Python Socket Chatbot Application

A multithreaded real-time chat application built using Python's native `socket` and `threading` libraries. This project uses a client-server architecture to handle multiple simultaneous user connections over TCP/IP sockets.

## Features

* **Multithreaded Architecture:** Handles multiple concurrent client connections effortlessly using standard Python threads.
* **TCP Socket Communication:** Ensures reliable and loss-less message delivery between clients and the central server.
* **Persistent Chat Logs:** Automatically records and saves all conversation history into a server-side text log file.
* **Modular Structure:** Cleanly divided into dedicated Server and Client modules.
